### 📖 Explicação Detalhada dos Exercícios

Cada exercício foi desenvolvido para reforçar conceitos específicos do Python. Abaixo você encontra a descrição, objetivo e conceitos abrangidos em cada desafio.

---

### **01_hello_world.py** 🌍
**Conceito:** Output e Strings

**Objetivo:**  
Introduzir o conceito básico de impressão em Python e familiarizar com a função `print()`.

**O que você aprende:**
- Como usar a função `print()`
- Trabalhar com strings (texto)
- Conceito de "Hello World" - primeiro programa universal

**Exemplo:**
```python
print("Olá, Mundo!")
```

**Conceitos-chave:** `print()`, strings, output no console

---

### **02_prime_number.py** 🔢
**Conceito:** Lógica, Loops, Condicionais

**Objetivo:**  
Implementar um algoritmo para detectar se um número é primo.

**O que você aprende:**
- Divisibilidade e conceito de números primos
- Uso de loops para iteração (`for`, `while`)
- Instruções condicionais (`if`, `else`)
- Operador módulo (`%`) para resto de divisão

**Exemplo de Lógica:**
```
Número 7 é primo? 
7 não é divisível por 2, 3, 4, 5, 6
Então 7 é primo!
```

**Conceitos-chave:** `for`, `while`, `if/else`, operador `%`, lógica de iteração

---

### **03_even_odd.py** ↔️
**Conceito:** Operador Módulo, Condicionais

**Objetivo:**  
Classificar números como pares ou ímpares.

**O que você aprende:**
- Usar o operador módulo (`%`) para encontrar resto
- Instruções condicionais para tomada de decisão
- Lógica booleana (verdadeiro/falso)

**Exemplo de Lógica:**
```
10 % 2 = 0  →  10 é PAR
7 % 2 = 1   →  7 é ÍMPAR
```

**Conceitos-chave:** operador `%`, `if/else`, estrutura condicional

- Função `print()` para output

**Exemplo de Lógica:**

**Conceitos-chave:** `input()`, `int()`, operadores aritméticos, `if/elif/else`
