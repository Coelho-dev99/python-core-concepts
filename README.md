## 🐍 Python Fundamentals Mastery - PT

Uma coleção abrangente de exercícios Python projetada para construir uma compreensão sólida dos conceitos fundamentais de programação.

### 📚 Visão Geral

Este repositório contém exercícios de programação cuidadosamente selecionados abrangendo os fundamentos essenciais do Python. Cada desafio foi desenvolvido para reforçar conceitos-chave e aprimorar habilidades de resolução de problemas.

### 📋 Tópicos Abrangidos

- **Operações com Strings** - Hello World, Detecção de Palíndromos
- **Lógica Numérica** - Números primos, Classificação par/ímpar
- **Estruturas de Dados** - Manipulação de listas, Operações com conjuntos
- **Funções e Algoritmos** - Tabuadas, Remoção de duplicatas
- **Processamento de Texto** - Contagem de vogais, Manipulação de strings

### 💻 Exercícios

#### Conceitos Básicos
- `01_hello_world.py` - Fundamentos do primeiro programa

#### Operações Numéricas
- `02_prime_number.py` - Algoritmo de detecção de números primos
- `03_even_odd.py` - Classificação de números pares e ímpares

#### Conceitos Matemáticos
- `04_calculator.py` - Operações aritméticas básicas
- `06_multiplication_table.py` - Tabuadas e estruturas de repetição

#### Manipulação de Estruturas de Dados
- `07_find_max_list.py` - Encontrando valor máximo em listas
- `08_remove_duplicates.py` - Removendo elementos duplicados
- `09_vowel_counter.py` - Análise de strings e contagem

#### Processamento Avançado de Strings
- `10_palindrome_checker.py` - Detecção de palíndromos

### 🚀 Como Usar

```bash
# Clonar o repositório
git clone https://github.com/Coelho-dev99/python-fundamentals-mastery.git

cd python-fundamentals-mastery
```
