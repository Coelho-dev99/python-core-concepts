🐍 Fase 1 - Fundamentos de Python
Este repositório reúne os primeiros desafios e exercícios da minha jornada de aprendizado em Python.

O objetivo desta fase foi construir uma base sólida em lógica de programação, desenvolvendo o raciocínio computacional e aprendendo os principais conceitos da linguagem Python.

🚀 Tecnologias Utilizadas
Python 3
VS Code
Git & GitHub

📚 Conceitos Praticados
Variáveis e Tipos de Dados
Operadores Matemáticos
Estruturas Condicionais (if, else, elif)
Laços de Repetição (for, while)
Listas
Strings
Funções
Manipulação de Dados
Resolução de Problemas

Consolidar os fundamentos da programação e desenvolver a capacidade de solucionar problemas utilizando Python.
